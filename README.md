# 就活管理ツール

日本での就活（応募進捗の管理 + 面接の考えの整理）のための、シンプルなフロントエンドのみのツールです。
フレームワークなし（素の HTML / CSS / JS）、データはブラウザの **localStorage** に保存されます。

> 開発は 3 阶段で進めます。**現在は第一阶段（核心看板）まで実装済み。**

## 使い方

`index.html` をブラウザで開くだけ（ローカルファイルのまま動きます）。
ログインもサーバーも不要。データは各ブラウザにそれぞれ保存され、他人とは共有されません。

## ファイル構成

```
index.html      … 画面の骨組み
css/style.css   … 見た目（水色テーマ・レスポンシブ）
js/data.js      … データ層（定数・localStorage・エクスポート/インポート）
js/app.js       … 描画と操作のロジック
```

コードはこれから学びながら触れるよう、日本語/中国語コメントを多めに入れています。

## 第一阶段でできること

- **2 つのモジュール切り替え**：気になる（未応募） / 応募済み（進捗管理）
- **気になる**：業界ごとに一覧表示。「応募した」で応募済みへ移動（業界も自動で引き継ぎ）
- **応募済み**：業界バー（すべて + 各業界、追加 / 削除）、お気に入りのみ表示、
  進捗ステージ別レイアウト（空のステージは非表示、順番は自由に変更可）
- **カード**：会社名 + 職種 + 色ブロック。面接が 7 日以内なら暖色でハイライト、
  お気に入りは右上に星マーク
- **詳細/編集**：会社名・職種・ステージ・ビザサポート・面接日・業界・ホームページ URL
- **選択モード**：一括削除（気になる） / 一括削除・一括お気に入り（応募済み）
- **空状態の案内**、削除前の確認
- **エクスポート / インポート**：全データを 1 ファイルにバックアップ・復元
